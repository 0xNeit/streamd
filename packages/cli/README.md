# @streamd/cli

The `streamd` command-line executable for tailing, querying, forwarding, storing, inspecting, and generating types from on-chain events.

## Commands

- `tail`, `query`, `forward`, `alert`, `store`, `watch`, `tx`, `inspect`, `transfers`, `balances`, `handles`, `name`, `check`, `compare`, `monitor`, `record`, `coverage`, and `codegen`.
- `--chain sui` loads `@streamd/sui` and `@mysten/sui` only when invoked (both are optional peers).

For full usage, flags, and configuration details, see the root [README.md](../../README.md).
